# 00 — Project Administration

**Purpose.** Hold the governing documents and the record of decisions so that every methodological choice in the thesis can be traced to a dated decision.

**Contents**
- `DGA Chpater 1.docx` — thesis Chapter 1 (governing statement of objectives).
- `Project_Overview_and_Objectives.docx` — earlier project brief (source of the reduced-gas study and the methodological safeguards).
- `decisions_log.md` — open and closed decisions.
- `timeline.md` — phase schedule (to be added once the start date is fixed).

**Procedure.** Any change of scope, dataset, class definition or method is entered in `decisions_log.md` with date, reason and who agreed it (student / supervisor) before work proceeds.

**Acceptance criteria.** No open decision in `decisions_log.md` blocks a phase that has started.

**Feeds thesis.** Chapter 1 (scope, limitations), Chapter 3 (justification of choices).
