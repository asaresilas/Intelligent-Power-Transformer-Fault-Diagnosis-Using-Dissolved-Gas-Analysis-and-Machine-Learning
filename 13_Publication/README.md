# 13 — Publication

**Purpose.** Journal manuscript drawn from the thesis core (ML pipeline, reduced-gas study, benchmark and disagreement analysis).

**Outputs**
- `target_journals.md` — shortlist built in Phase 2 from where the reviewed papers were published; scope, indexing and author guidelines checked on each journal's own site.
- `manuscript/` — title, abstract, introduction, materials and methods, results, discussion, conclusion.
- `reproducibility_statement.md` — data sources with DOIs, code availability, software versions, seeds.
- `cover_letter.md`.

**Method-section checklist**
- Data sources, label provenance and exclusions stated.
- Preprocessing fitted within training folds; validation scheme and seeds stated.
- Metrics per class with confidence intervals; statistical tests named.
- Conventional methods: standard and edition cited; treatment of "no diagnosis" cases stated.
- Limitations stated plainly (dataset size, five-gas panel, laptop deployment).

**Acceptance criteria.** Manuscript numbers identical to `11_Results/`; supervisor and co-author approval recorded; journal formatting requirements met.
