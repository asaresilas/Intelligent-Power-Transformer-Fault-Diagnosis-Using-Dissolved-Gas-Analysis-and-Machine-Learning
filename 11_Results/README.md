# 11 — Results

**Purpose.** Hold the final figures and tables used in the thesis and paper.

**Structure.** `figures/` (vector PDF/SVG + 300 dpi PNG), `tables/` (CSV + formatted version).

**Rules**
- Everything here is produced by a script in folder 04, 06, 08 or 09 — no hand-typed numbers.
- `manifest.csv` lists each item: file, generating script, source run folder in `07_Experiments/`, thesis figure/table number.

**Acceptance criteria.** Deleting this folder's contents and re-running the scripts recreates every item.

**Feeds thesis.** Chapter 4; manuscript figures and tables.
